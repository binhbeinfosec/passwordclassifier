# User-Created Password Classifier (Hierarchical Model)

This repository contains the official implementation of the Hierarchical Classification Model described in the research paper: **"Classifying user-created passwords using machine learning and natural language processing techniques,"** published in *Internet of Things* (Elsevier).

This tool classifies user-created passwords into three categories: **Weak (0)**, **Normal (1)**, and **Strong (2)**, utilizing a hierarchical approach combining **Bag-of-Words (BoW)** and **Logistic Regression**.

## Features

* **Hierarchical Architecture:** Splits the classification problem into two stages to handle class imbalance effectively:
    1.  Stage 1: Distinguishes **Weak** passwords from the rest (Normal/Strong).
    2.  Stage 2: Distinguishes between **Normal** and **Strong** passwords.
* **High Performance:** Designed to maximize recall for weak passwords to minimize security risks.
* **Lightweight:** The trained model is serialized into a compact `.pkl` file for fast inference (~milliseconds per password).

## Usage

The tool consists of three main components:
1.  `model_utils.py`: Contains the `HierarchicalPasswordClassifier` class definition.
2.  `trainer.py`: Used to train a new model from a dataset.
3.  `classifier.py`: Used to classify passwords using a trained model.

### 1. Training the Model

If you wish to train the model on your own dataset:

```bash
python3 trainer.py -i PATH_TO_TRAINING_DATASET -o MODEL_NAME.pkl
```

#### Data Preparation Guidelines
To achieve the performance described in the paper, your training dataset should adhere to the following standards:

* **Source:** Use real-world leaked passwords (e.g., from Collection #1 or similar breaches) to capture actual user behaviors.
* **Format:** A text file where each line contains `PASSWORD LABEL` (separated by space).
    * Labels: `0` (Weak), `1` (Normal), `2` (Strong).
* **Labeling:** Ground truth labels must be generated by a reliable Password Strength Meter (PSM), such as **SMMI-PSM**.
* **Cleaning:** * Remove passwords with non-ASCII characters.
    * Filter passwords length between 4 and 20 characters.
    * Ensure the dataset contains unique entries (deduplicated).

### 2. Classifying Passwords

You can use the provided pre-trained model (if available) or your own trained model.

**Interactive Mode:**
Run the classifier to enter passwords manually via the command line.

```bash
python3 classifier.py -m MODEL_NAME.pkl
```

**File Mode:**
To classify a large list of passwords (one password per line).

```bash
python3 classifier.py -m MODEL_NAME.pkl -i TEST_FILE -o RESULT_FILE
```
